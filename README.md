# SQL Fondamentaux — Niveau 1

> Apprendre à lire les données avec SQL — [BriqueParBrique](https://briqueparbrique.github.io)

Ce dépôt contient le parcours d'apprentissage « SQL Fondamentaux — Niveau 1 »,
conçu comme un mini-onboarding en six étapes pour comprendre ce qu'est une base
de données, installer ses outils et écrire ses premières requêtes de lecture.

**Site** : [briqueparbrique.github.io/sql-fondamentaux-brique-1](https://briqueparbrique.github.io/sql-fondamentaux-brique-1/)

Aucun prérequis : c'est le premier niveau du parcours.

## Parcours

1. C'est quoi SQL ?
2. Installer son environnement
3. SELECT et FROM
4. WHERE
5. ORDER BY et LIMIT
6. Mini-projet

À la fin du niveau, on sait interroger une table : choisir des colonnes,
supprimer les doublons avec `DISTINCT`, filtrer avec `WHERE` (`=`, `<`, `>`,
`BETWEEN`, `IN`, `LIKE`, `AND`, `OR`), trier avec `ORDER BY` et limiter avec
`LIMIT`.

Les exercices se pratiquent sur **SQLite**, sans installation obligatoire
([sqliteonline.com](https://sqliteonline.com/) suffit).
